# Smart Food Rescue Network

## Description
Smart Food Rescue Network is a Flask-based web application that connects food donors with NGOs and volunteers to reduce food wastage and help people in need.

## Features

- User Registration
- Login
- Donor Dashboard
- NGO Dashboard
- Volunteer Dashboard
- Admin Dashboard
- Donate Food
- Request Food
- SQLite Database

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Run the Project

Install Flask:

```bash
pip install -r requirements.txt
```

Create the database:

```bash
python database.py
```

Run the project:

```bash
python app.py
```

Open in your browser:

```
http://127.0.0.1:5000
```
